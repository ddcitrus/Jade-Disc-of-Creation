# 造化玉碟 · 独立版

一个跑在自己电脑上的修仙文字世界：你在网页里输入行动，AI 负责把接下来的剧情写出来，
遇到打斗时会切进 3D 战棋回合制。

二创自DC_Prism_Hajimi

---

## 一、开始之前

你只需要装一样东西：**Node.js**（18 以上，推荐 20 或更新）。

去 <https://nodejs.org/> 下 LTS 版，一路下一步装完就行。其他什么都不用装。

---

## 二、怎么启动

拿到项目后（clone 或下载解压都行），**双击根目录的 `启动游戏-网页版.bat`**。

第一次启动会慢一些（下载依赖 + 构建前端，大概一两分钟），之后就是自动构建、
自动启动、自动打开浏览器。窗口里出现 `backend: http://127.0.0.1:8346` 就说明起来了。

**那个黑窗口要一直开着**，关掉游戏就停了。以后每次玩，还是双击同一个 bat。

---

## 三、第一次进游戏：先配 AI 接口

**不配接口写不出正文。** 启动页进 **系统设置 → 接口库**，新增一条：

| 要填的 | 说明 |
| --- | --- |
| 名称 | 随便起 |
| 接口地址 | OpenAI 兼容的地址，例如 `https://api.xxx.com/v1` |
| 密钥 | 你的 API Key |
| 模型 | 模型名，例如 `deepseek-chat`、`gpt-4o` |

填完在 **通道选择** 里选中它。任何 OpenAI 兼容的服务都能用。

配好后回到启动页点 **开始新人生**，按引导建好角色，就能开玩了。

---

## 四、怎么玩

在主界面的输入框里写你想做的事（「去坊市买把铁剑」「闭关修炼一个月」），回车，AI
就会把这段剧情写出来。正文写完后程序会自动把变化（升级、受伤、得到物品……）记进存档。

常用页面：

- **故事** —— 主界面，剧情和输入都在这
- **世界书** —— 给世界加你自己的设定
- **查看人物** —— 点开看角色卡、管储物袋和装备
- **快照** —— 自动/手动存点，可以回退到任意一个存点
- **天道助手** —— 有问题直接问 AI
- **设置** —— 接口、篇幅、文风、主题等

---

## 五、常见问题

**Q：提示「未检测到 client/dist」**
前端还没构建，双击一次 `启动游戏-网页版.bat` 即可。

**Q：正文写不出来 / 一直转圈**
去 **设置 → 接口库** 检查地址、密钥、模型都填了，并在「通道选择」里选中了它。

**Q：改了代码/设置但没变化**
双击一次 `启动游戏-网页版.bat`，它会自动重新构建。

**Q：一个回合等很久**
慢的是 AI 生成那一步，跟电脑性能无关，换更快的模型最有效。

**Q：你的数据都在哪**
全部在 `server/data/` 文件夹里 —— 存档、设置、世界书都在这。想备份就整个文件夹拷走。
